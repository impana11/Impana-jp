Here’s a complete mini full-stack Task Manager web application using MERN stack 

(MongoDB, Express.js, React, Node.js) with authentication, CRUD operations, task 

categorization, status updates, and search functionality.

Tech Stack Used

Frontend: React.js, React Router, Axios, Bootstrap

Backend: Node.js, Express.js, MongoDB (Mongoose)

Authentication: JSON Web Token (JWT), bcrypt.js

Database: MongoDB (local or cloud – MongoDB Atlas)
